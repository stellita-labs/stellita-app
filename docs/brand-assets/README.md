# Stellita Brand Assets

This directory stores offline brand assets, print materials, color palettes, and high-resolution master logos that are not directly served over the web client root.

- `color-palette.png`: Master color palette definition
- `favicon-512.png`: High-resolution 512x512 app icon master
- `logo-slogan.png`: Horizontal logo with official tagline
- `logo-social-white.png`: Social media banner asset
- `logo-wordmark.png`: Typography wordmark banner
